# Clawbrowser Private

أتمتة متصفح محلية مع تحكم صريح في الشبكة.

يهدف هذا الفرع إلى ملفات تعريف محلية وأتمتة CDP محلية، مع السماح بالاتصال بالمواقع المعتمدة ونطاقاتها الضرورية فقط. يجب إزالة اتصالات التشغيل بخدمات تفعيل Clawbrowser وبصماته والمرحلات والقياس عن بعد.

## حالة التطوير

تحديث الوثائق هو المرحلة الأولى. ما زال التنفيذ الموروث يتضمن فحص API key وجلب البصمات عن بعد والتحقق الخارجي. التشغيل المحلي وعزل الشبكة بحاجة إلى تنفيذ واختبار.

## الإعداد والتحقق

استنسخ المستودع لفحص الشفرة أو تطويرها. ما زال المثبت والإصدار المحليان المتحقق منهما قيد الإعداد. يتطلب البناء نسخة Chromium منفصلة وأدوات مثبتة الإصدارات. تُدار تنزيلات البناء بشكل منفصل عن سياسة شبكة التشغيل.
